# About

Settings / legal identity for the native (and web) console binary.

- Tokens from `src/lib/theme.ts` only (works in both themes) — no marketing chrome, no website Master.
- Show **license**, **version / build**, and **Corresponding Source URL** as labeled fields (never color-only). Native back control min height 44px with an accessible name.
- Source URL is the exact git revision used to produce this artifact (`/tree/<commit>`), never `trunk`.
- Unsigned users may open `/about` (AGPL network-use disclosure on the binary).
